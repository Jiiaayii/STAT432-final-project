# STAT432 Final Project: Student Depression Prediction

This repository contains the full code and analysis for our STAT432 final project, which focuses on predicting depression levels among students based on survey data.

## 📁 Project Structure
- `code/`: All scripts for data cleaning, EDA, modeling, and evaluation
- `data/`: Summary of input dataset structure (raw data not included due to size/privacy)
- `README.md`: Project overview and instructions

## 📂 Data Source
The dataset was obtained from [Kaggle: Student Depression Dataset](https://www.kaggle.com/datasets/adilshamim8/student-depression-dataset).


## 🧠 Methods Used
- Logistic Regression (LASSO, Ridge)
- K-Nearest Neighbors (KNN)
- Random Forest & XGBoost

## 🔧 How to Run
Open `code/data_preprocessing.R` to load and clean the data. Each modeling script is self-contained and can be run independently once the data is prepared.
